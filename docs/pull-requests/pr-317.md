# [PR 317](https://github.com/vig-os/scitadel/pull/317) docs(adr): ADR-008 scitadel-hub — lab corpus server, repo split, tessera storage, free-key sync

## Description

Adds **ADR-008 (Proposed)**: `scitadel-hub`, a lab-level corpus server in a separate repo. It keeps a searchable copy of the OpenAlex and USPTO patent corpora as sealed, add-only tessera products, queries them with DataFusion, and serves BM25, vector and graph retrieval to scitadel clients through a `hub` source adapter that falls through to the live APIs.

This PR is the ADR only. Implementation is tracked in epic #311 (H0 #313, H1 #314, H2 #315, H3 #316, H4 #318, H5 #319, H6 #320, H7 #321), with the storage-format work upstream in vig-os/tessera#778 and storage in gerchowl/g-fleet#1121.

## Changes Made

- `docs/decisions/ADR-008-2026-11-08-scitadel-hub.md`, covering:
  - **Context:** PatentsView retired 2026-03-20; OpenAlex's free $1/day key, with the sync filters behind Member+; labs repeating the same queries; anvil's GPU and System One (#246).
  - **Decisions:**
    - the repo split and its seam (a `hub` adapter plus a protocol crate);
    - tessera storage (sealed, add-only);
    - DataFusion, not DuckDB;
    - BM25, vector and graph search as tessera derived caches, with no graph database;
    - the free-key OpenAlex sync strategy (snapshot subset, publication-date subscriptions, rolling 100-ID refresh), with Member+ as an option;
    - the USPTO patent corpus, published on Hugging Face as **`.tsra` only**;
    - PatentRef as a stopgap only;
    - infrastructure (versitygw store, NVMe working copy, GPU batch jobs only).
  - **Second commit (`1d94d69`) adds:**
    - **§9 document model:** Arrow/Vortex shard blocks sorted by `(work_id, ord)`; lossless figure storage (SVG / JPEG XL); Qwen3-VL-Embedding figure vectors; Typst/HTML/Markdown as render views only; no per-paper `.tsra` in the hub.
    - **§10 tiered extraction cascade:** T0 parse → T1 tools → T2 System One → T3 Qwen VL on sage → T4 Opus. Licence-gated and budget-capped, with every verdict in provenance.
    - **§11 provenance:** of every process, including inputs that are not held.
    - **§12 artefact store:** outside the DB, with raw retention by the cost of fetching again, licence classes, upload-on-acquire and `detach`.
    - **§2 layout and lifecycle:** base + delta, compaction, retention.
    - **§13 quality:** golden set, red/green loop and random-sample QC.
    - **§6 patents:** use the same cascade.
    - Cites tessera#779–#782.
  - **Third commit (`10d9033`) adds §14 "Serving model: where compute runs"** (decision 14): CPU serving + GPU ingest through `gpu_submit`; client-side query embedding as the default with explicit model-mismatch rejection; snippet-only responses; `reranked: false` graceful fallback when the GPU rerank queue is busy; offline-mode routing to a detached subset; and hub sizing *(estimates)*.
  - **Fourth commit (`d65ab3e`) adds the owner's 2026-11-08 BUILD-FIRST decision and fixes the §7 ↔ #316 seam:**
    - **Decisions 15–17:** phase 1 ingests only CC0/CC-BY/public-domain content per item, so the phase-1 corpus is also HF-publishable on one licence surface; licence-gated features (H4 entitlement classes, local display of licensed content, COUNTER 5.1/SUSHI) are designed but **disabled** in phase 1; the ETH Library approach (Research Collection harvest agreement, CopA Art. 24d reading, publisher local-hosting addendum via the Consortium of Swiss Academic Libraries, COUNTER) comes **after** a running demo.
    - **New §15 "Sequencing: build first, licence-clean":** the phase-1 source list (US patent XML + PGPub, OpenAlex, PMC OA `oa_comm`, SureChEMBL, DataCite/Crossref metadata, OpenAIRE Graph, OpenCitations, DOAJ, DBLP, ACL Anthology 2016+, DOAB/OAPEN, ORCID, OSF Preprints, HAL metadata + CC-BY/CC0 subset, Research Square, Zenodo CC-BY subset, ChemRxiv CC-BY subset, arXiv CC-BY/CC0 subset, bioRxiv/medRxiv CC-BY/CC0, Europe PMC CC-BY/CC0, INSPIRE-HEP metadata, Retraction Watch); the maximum-depth ingest shape (structured sources first, Crossref TDM-link harvester for CC-BY/CC0 publisher full text, HF as cold store + anvil hot set, embedding levels and GPU budget); retraction flags as a QC must-have joined at index-build time; the DEFERRED set (Research Collection bulk, CORE, S2ORC, unlicensed bronze/green, paywalled caches, EPO paid bulk, Swiss repositories, NASA ADS, RePEc, SWH source code, Preprints.org, BASE); and what phase 2 unlocks.
    - **§7 protocol fix:** adds a `capabilities` row to the client/hub protocol table — per index: embedding model id, version, dims, Matryoshka truncation, BM25 analyzer, rerankers — the separate call #316 defines. `coverage` stays scoped to what the hub holds.
    - **§14 consistency:** cites `capabilities`, not `coverage`, as the embedder advertisement; consequences updated.
    - Open question 12 asks about Crossref's `license` + `link[intended-application=text-mining]` fields and per-publisher TDM terms.
    - Grounded in the live extension of issue #323 (Aggregators and additional open sources).
  - Alternatives considered, consequences and risks (tessera pre-1.0, tessera#628 string size, anvil's 2 TB disk, PatentRef durability), and open questions for the owner.
