# [PR 219](https://github.com/vig-os/scitadel/pull/219) fix(deps): upgrade ratatui 0.30 + crossterm 0.29 (lru advisory)

Clears the last Dependabot alert from #215: `lru < 0.16.3` (`IterMut` Stacked Borrows unsoundness). ratatui 0.29 pinned `lru 0.12`; ratatui 0.30 goes through `ratatui-core`, which requires `lru ^0.18`.

```
lru v0.18.5
└── ratatui-core v0.1.2
    ├── ratatui v0.30.2
    ├── ratatui-crossterm v0.1.2
    ├── ratatui-macros v0.7.2
    └── ratatui-widgets v0.3.2
```

**No source changes needed**: 0.30's breaking changes don't touch our surface. `Block::title` now takes `Into<Line>`, which every call site already satisfies because they pass strings. We have no custom `Backend`, no `Frame::size`, and no `WidgetRef`. crossterm 0.29's only break is `KeyModifiers` `Display`, which we don't use.

**Stacked on #218 (and #217)**: this branch merges them so the three dependency PRs land in order without lockfile conflicts. Once those two squash-merge, this diff shrinks to `Cargo.toml`, `Cargo.lock` and `CHANGELOG.md`.

**Verified** with the CI toolchain (rustc 1.98.1):
- fmt and `clippy --workspace --all-targets -D warnings` are clean.
- `cargo test --workspace` passes all 517 tests.
- All 17 TUI VHS tapes complete on both 0.29 and 0.30. 32 of 60 screenshots are byte-identical. The rest differ only in keystroke timing (a frame captured before or after a key landed); wherever both runs captured the same app state, the images match.
