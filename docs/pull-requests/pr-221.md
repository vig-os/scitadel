# [PR 221](https://github.com/vig-os/scitadel/pull/221) fix(release): pass bumped files to commit-action; undo 0.8.0 freeze

The first 0.8.0 `prepare-release` went green, but `release/0.8.0` came out **without** the version bump. `cargo set-version` and the plugin pin ran, then `commit-action` logged `No files to commit`: its git-status auto-detection finds nothing in this job. So every crate and the plugin pin stayed at 0.7.0.

- `prepare-release-extension.yml` now collects the changed paths itself, passes them as `FILE_PATHS`, and **fails** if the bump changed nothing, so a release branch can never go out on the old version again.
- Reverts the changelog-freeze commit (`efe98df`) so `prepare-release` can be re-run for 0.8.0. The half-prepared `release/0.8.0` branch and draft PR #220 are removed.

Refs: #207
