# [PR 243](https://github.com/vig-os/scitadel/pull/243) chore(deps): drop the invalid uv Renovate manager on main

Renovate reads its config from the default branch. On `main`, `enabledManagers` still lists `uv`, which is not a Renovate manager, so Mend reports "The following managers configured in enabledManagers are not supported: \"uv\"" and every run stops there.

#241 fixed this on `dev`, but `dev` is 9 commits ahead of `main`, so the fix would wait for the next release. This PR puts the same one-line change on `main` now. `renovate.json` becomes byte-identical to `dev`'s copy, so the sync back to `dev` merges without conflict.

- `enabledManagers`: `["github-actions", "pep621", "uv", "npm"]` → `["github-actions", "cargo"]`
- `renovate-config-validator --strict` exits 0
- No CHANGELOG entry: the `dev` entry from #241 ships with the next release

Refs: #240
