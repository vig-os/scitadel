## Four things a reviewer should look at

**1. A cap the ADR states that nothing could enforce.** §3 caps tier 4 at "≤ 50 works per publisher, **≤ 150 works total**". The per-publisher half is `BucketPolicy::work_cap`, but a policy is per-bucket by definition, so the total had no home. Left alone, four publishers at 50 works each authorises 200 — the ceiling would silently be per-publisher. `SqlitePacer::with_total_caps` adds the missing cross-bucket count inside the same transaction, so it cannot race the per-bucket one. Tests pin both that it binds and that an *unconfigured* ceiling stays unbounded.

**2. Login-redirect detection is token matching, not substring.** Naive `contains("auth")` flags `…/papers/authors` and `middle-earth-association.org` — and publisher URLs are full of `authors`. Matching is whole-token, host labels and path segments only, never query or fragment, with separator-squeezing so `sign-in` == `signin`.

**3. A latent publish break, caught and fixed.** `scitadel-adapters` now depends on `scitadel-http`, and `publish-crates.yml` publishes from a hardcoded ordered list — so `cargo publish -p scitadel-adapters` would have failed on an unresolvable dependency. `scitadel-http` is inserted after `scitadel-core`. The other release workflows derive their list from `cargo metadata` and needed nothing.

**4. Seven behaviour changes, listed rather than buried** — in the commit message of `05ac4ca`. The one worth flagging here: **login/SSO redirects are now refused** where previously the login page's HTML was stored as `paywall`/`unknown`. ADR-intended (`needs_login` lands in S2), but a real output change for those publishers.

## Deliberate non-fixes, tracked separately

- **#276** — the OpenAlex API key is still in a query string, so it reaches error strings and the TUI. Pre-existing. This change deliberately keeps the leak no worse: forwarding `FetchError`'s URL verbatim would have put the key into every `tracing` line.
- **#275** — `doi.org` has no pacing bucket, so S2's identity check will resolve every DOI at the unknown-host 5 s default. No limit was invented.
- The import-flat importer lives in `scitadel-adapters`; ADR §3 puts importers in a future `scitadel-acquire` crate, so it should move.

## Two subagent collisions, for the record

Running two agents in one working tree lost work once: one agent's `cargo fmt` reordered `core/models/mod.rs` under another agent's edit. The second agent noticed, stopped rather than racing, and wrote a handoff. Subsequent work was serialised and committed per piece. Worth remembering that subagents share a tree unless given separate worktrees.
