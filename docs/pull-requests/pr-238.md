# [PR 238](https://github.com/vig-os/scitadel/pull/238) feat(openalex): title-aware search + DOI resolver

## Summary

Closes the two gaps #210 hit during citation verification: OpenAlex `search` couldn't find papers by exact title, and there was no DOI -> metadata tool.

- **`search --field <mode>` / MCP `search { field }`** — routes OpenAlex through `filter=title.search:` (`title`) or a title-first broad-fallback merge (`auto`). Default `any` keeps the pre-#210 broad `search=` behaviour so existing callers see no change. Only OpenAlex sees the flag; other adapters ignore it. Non-default modes are persisted into the search `parameters` so `history` / `find_similar_searches` reflect how it was run.
- **`resolve-doi <doi>` (CLI) / `resolve_doi` (MCP)** — DOI → full Paper via OpenAlex `/works/doi:<doi>`, with scitadel-core DOI validation before the wire, `Ok(None)` on 404, and DB persistence by default (existing-row id preserved so annotations keep resolving).

Existing OpenAlex auth handling from #213 flows through unchanged (`OpenAlexAuth::email` + `api_key` on every request).

## Probe evidence

Live probes against `api.openalex.org` for the issue's Schwarz-1978 case:

| Endpoint | Hits | Target rank |
|---|---|---|
| `?search=Estimating+the+Dimension+of+a+Model` | 4,076,151 | fluctuates in top 5, historically absent |
| `?filter=title.search:Estimating+the+Dimension+of+a+Model` | 474 | **1** |
| `?filter=display_name.search:…` | 474 | **1** (aliased server-side to `title.search`, so we standardise on the latter) |

For fuzzy titles that mix in author names (`Improving FISTA faster smarter greedier Liang Schonlieb`), `title.search:` correctly returns 0 while broad still surfaces topically-adjacent stuff — this is why `Any` stays the default and `Auto` merges the two (title first, broad fills the tail).

## New surface

| Where | Surface |
|---|---|
| CLI | `scitadel search --field any\|title\|auto` (default: `any`) |
| CLI | `scitadel resolve-doi <doi> [--json] [--no-save]` |
| MCP | `search { field: "any"\|"title"\|"auto" }` (optional, defaults to `any`) |
| MCP | `resolve_doi { doi, save? }` returns `{paper, saved}` |
| Adapter | `OpenAlexAdapter::search_field`, `fetch_paper_by_doi`, `with_default_field(SearchField)` |
| Builder | `scitadel_adapters::build_adapters_with_field(..., openalex_field)` |

## Smoke test (release binary)

Both live-verified against `api.openalex.org` with the built binary:

- `scitadel search "Estimating the Dimension of a Model" --sources openalex --field title -n 5` returns the Schwarz-1978 paper (DOI `10.1214/aos/1176344136`) in the top 5.
- `scitadel resolve-doi 10.1214/aos/1176344136` prints title / authors / year / journal / OpenAlex id and persists the row.
